# Anne-Will-Netzwerkanalyse

# EDGE-Attribute

**id**  
(eindeutige Codierung des Knoten)   
Kürzel der Gäste, jede ID entspricht einem Gast
sowie Codierung der Sendungen 500-503

**relation**
  
1 = *guest* Verbindung von Gast zu Sendung.  
2 = *member* Verbindung von Gast zu Partei.  



# NODE-Attribute  

  id,name,type,party,sector,country

**id**  
Identische ID wie aus der edgelist zur Identifikation der Knoten, sowie Sendungen von 500-503.

**name**
Vor- und Nachname

**type**
1= Gast
2= Folge

**party**
Parteizugehörigkeit

**sector**
z.B. Politik, Wissenschaft, Journalismus...

**country**
Staatszugehörigkeit
